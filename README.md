Sistema de Cadastro de Clientes em C

Projeto desenvolvido em linguagem C para praticar fundamentos de programação e validação de dados.

O sistema permite cadastrar clientes através do terminal, coletando:

- Nome completo
- Login
- E-mail
- Senha

O projeto também realiza validações básicas dos dados informados:

- Nome: verifica se possui nome e sobrenome.
- E-mail: verifica a presença do "@" e se existe conteúdo após ele.
- Senha: verifica se possui mais de 6 caracteres, letra maiúscula e combinação de letras e números.

Conceitos praticados

- "struct"
- Funções
- Arrays
- "fgets()"
- "printf()"
- "if/else"
- "switch"
- "do/while"
- Manipulação e validação de strings
